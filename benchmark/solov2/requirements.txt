# Cùng lý do detectron2 không nằm trong file của Mask R-CNN: có máy thì lấy

#
#     KHỐI A trong ../torch.txt (torch 2.4/cu121)  -> wheel dựng sẵn, vài giây
#     KHỐI B (CUDA 13, Blackwell)                  -> build từ nguồn, 20-120 phút
#
#     python scripts/setup_env.py --only mmcv                 # wheel
#     python scripts/setup_env.py --only mmcv --build-mmcv    # từ nguồn
#
# VÌ SAO KHÔNG CÓ WHEEL MỚI HƠN. Dò thẳng chỉ mục của OpenMMLab:
#
#     cu118/torch2.3.0  cu118/torch2.4.0     -> 200
#     cu121/torch2.3.0  cu121/torch2.4.0     -> 200
#     cu124/*  cu128/*  cu130/*  torch2.5+   -> 404, không tổ hợp nào tồn tại
#
# Và họ đã dừng: mmcv 2.2.0 ra 24/04/2024, mmdet 3.3.0 ra 05/01/2024. Commit
# gần đây trên nhánh main chỉ là NPU (Ascend) và MUSA, không đụng CUDA.
#
# HỆ QUẢ: torch 2.4/cu121 có trước Blackwell nên KHÔNG có kernel sm_120. Với
# KHỐI A thì SOLOv2 không chạy được trên RTX 50xx, RTX PRO 6000 hay B200 —
# chết ngay lời gọi kernel đầu tiên:
#
#     RuntimeError: CUDA error: no kernel image is available for execution
#
# Muốn chạy trên Blackwell thì phải KHỐI B + build mmcv. Có người làm được và
# ghi lại: mmcv#3327 (11/02/2026), torch 2.7 + CUDA 12.8.
#
# Kèm theo một cái bẫy mà công thức đó không nhắc: torch >= 2.6 đổi mặc định
# `torch.load(weights_only=True)`, còn checkpoint mmdet chứa dict `meta` với
