# torch==2.11.0+cu130
# torchvision==0.26.0+cu130

# Vì sao 2.11 mà không phải bản mới nhất: đây là bản DUY NHẤT ta có bằng
# chứng của chính mình — detectron2 0.6 đã build và import được với torch
# 2.11 + Python 3.13 trên molab. mmcv thì có người báo build được ở torch 2.7
# (mmcv#3327). Càng lên cao càng xa hai mốc đó, mà cả detectron2 0.6 (2021)
# lẫn mmcv 2.2.0 (04/2024) đều không còn ai bảo trì.
#
# Cặp torch/torchvision hợp lệ trên cu130, nếu muốn đi cao hơn:
#
#     2.9.0/0.24.0   2.9.1/0.24.1   2.10.0/0.25.0  2.11.0/0.26.0
#     2.12.0/0.27.0  2.12.1/0.27.1  2.13.0/0.28.0  2.14.0/0.29.0
#
# ĐỔI SANG KHỐI NÀY THÌ mmcv KHÔNG CÒN WHEEL. OpenMMLab chỉ phát hành cu118 và
# cu121, tới torch 2.4 — dò trực tiếp thì mọi tổ hợp cu124/cu128/cu130 và
# torch2.5+ đều trả 404. Build bằng:
#
#     python scripts/setup_env.py --only mmcv --build-mmcv
